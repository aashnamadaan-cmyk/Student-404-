STUDENT 404: NOT FOUND — SCRAPBOOK REDESIGN

Files:
- index.html: redesigned responsive scrapbook-style interface
- style.css: vibrant pastel retro design
- server.c: C HTTP server and report storage backend
- reports.txt: sample reports

Windows + MinGW:
1. Open this folder in VS Code.
2. Run: gcc server.c -o server.exe -lws2_32
3. Run: .\server.exe
4. Open http://localhost:8080
5. Keep the terminal open while using the site.

The server is a local beginner demonstration, not suitable for public deployment.
